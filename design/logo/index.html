TASKR logo options

Six icon directions. Each is an SVG on a 64×64 grid in a single colour (currentColor), so it can be recoloured, resized and animated part by part. Every option is shown as a lockup on a dark gradient like your references, on white, as app icons and at favicon sizes. Press Play animation to see how it could move. The word "taskr" is set in a placeholder typeface (Sora); we refine it once you pick an icon.
